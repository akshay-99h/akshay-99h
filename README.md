## What I build

- **Payment platforms** - wallets, transaction ledgers, recharges, bookings, and the admin reconciliation nobody sees but everybody needs.
- **Real-time systems** - game analytics dashboards, live event streams, leaderboards, WebSocket fan-out.
- **Multi-role marketplaces** - food ordering across customers, restaurants, delivery partners, and admins, each with its own permission surface.
- **Internal tooling** - node-based scenario builders, conditional flow editors, and content management for non-technical teams.
- **Offline-first apps** - PWAs backed by IndexedDB with sync and conflict handling that survives a bad network.
- **Auth and access control** - session and token flows, RBAC across many user types, audited from day one.
- **Developer experience** - opinionated backend scaffolds with linting, hooks, and security defaults baked in, so project two starts faster than project one.
- **Deployment pipelines** - Dockerized services on ECS behind load balancers, with CI/CD and certificate management that runs unattended.
- **AI features** - LLM integrations and RAG-style retrieval built into real products, not demo notebooks.
